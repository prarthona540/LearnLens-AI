# LearnLens AI

## Project Overview

LearnLens AI is an AI-powered Personalized Learning Intelligence Platform.

The main purpose of this project is to understand how individual students learn and provide personalized learning recommendations using Artificial Intelligence.

Unlike traditional learning platforms that provide the same learning experience for every student, LearnLens AI analyzes student learning behavior and creates a customized learning journey.


## Project Goal

The goal of LearnLens AI is to transform traditional learning into an intelligent and personalized experience.

The system will analyze:

- Quiz performance
- Assignment results
- Learning activities
- Study patterns

and generate:

- Personalized study plans
- Weak topic detection
- Learning recommendations
- Exam readiness insights


## Target Users

### Students

Students can:
- Upload learning materials
- Generate AI summaries
- Take AI-generated quizzes
- Track learning progress


### Teachers

Teachers can:
- Monitor student performance
- Identify weak topics
- Analyze learning progress
