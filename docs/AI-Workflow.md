# AI Workflow

## Note Analysis Flow

Student uploads learning material.

↓

System extracts text from document.

↓

Data is sent to Gemini AI API.

↓

AI generates:

- Summary
- Important topics
- Key concepts

↓

Results are stored and shown to student.
